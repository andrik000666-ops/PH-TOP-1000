# PornHub TOP 1000 — Random

Небольшой Python\-скрипт для выбора актрис из списка **PornHub TOP 1000** и ведения собственных результатов\.

Скрипт позволяет выбрать случайную актрису, найти её по номеру или псевдониму, поставить оценку и сохранить результат в отдельный текстовый файл\.

## Возможности

- **Случайный выбор:** нажмите Enter без ввода — скрипт выберет случайную актрису, которая ещё не попадалась при случайном выборе\.
- **Выбор по номеру:** введите ID от 1 до 1000\.
- **Поиск по псевдониму:** можно ввести имя актрисы; поиск не зависит от регистра, пробелов и знаков препинания\.
- **Подсказки при ошибке:** если точное совпадение не найдено, скрипт попробует предложить похожие псевдонимы\.
- **Личная оценка:** после выбора можно поставить оценку от 1 до 20, указать время и добавить короткий комментарий &#40;до 5 слов&#41;\.
- **Сохранение истории:** выбранные ID и личные результаты сохраняются между запусками\.

## Структура папок

Разместите файлы примерно так:

```text
PornHub TOP 1000/
│
├── Top Random.py
│
├── исходники/
│   └── PornHub - TOP 1000.txt
│
└── Результаты/
    ├── used_models.json
    └── Мои результаты.txt
```

Папка `Результаты` и файлы внутри неё создаются автоматически при первом запуске и сохранении результата\.

## Формат исходного файла

Исходный файл должен называться `PornHub - TOP 1000` &#40;расширение может быть `.txt`&#41; и находиться в папке `исходники`\.

В нём должно быть ровно 1000 непустых записей\. Каждая запись должна содержать пять полей, разделённых символом `|`:

```text
ID | Псевдоним | Количество видео | Просмотры | Место в рейтинге
```

Пример формата:

```text
1 | Example Name | 123 | 456789000 | 1
```

ID должны быть уникальными и идти в диапазоне от 1 до 1000\. Скрипт проверяет количество записей и ID при запуске\.

## Как пользоваться

1. Установите Python 3, если он ещё не установлен\.
2. Скачайте репозиторий или скопируйте его файлы\.
3. Убедитесь, что исходный файл находится в папке `исходники`\.
4. Запустите `Top Random.py`\.
5. Введите номер или псевдоним либо нажмите Enter для случайного выбора\.
6. После выбора укажите оценку, время и комментарий\.

### Как работает случайный выбор

При случайном выборе скрипт исключает ID, которые уже сохранены в `Результаты/used_models.json`\. Когда все 1000 ID будут использованы, случайный выбор перестанет работать и сообщит об этом\.

Если ввести номер или псевдоним вручную, актрису можно выбрать повторно — ручной выбор не блокируется историей\.

Чтобы начать случайный выбор заново, удалите файл `Результаты/used_models.json`\. Это сбросит список использованных ID\. Файл `Мои результаты.txt` при этом не удалится\.

## Где хранятся результаты

- `Результаты/used_models.json` — ID, уже использованные при случайном выборе\.
- `Результаты/Мои результаты.txt` — личные записи с датой, именем, местом в рейтинге, просмотрами, оценкой, временем и комментарием\.

## Обновления и источник данных

Это статичная копия списка TOP 1000\. Проект не обновляет рейтинг автоматически, а автор не гарантирует актуальность данных после даты их сбора\.

Данные предназначены для ознакомления и личного использования\. Права на исходные данные и товарные знаки принадлежат их соответствующим владельцам\.

## Второй скрипт

Простой рандомайзер (TOP-1000 Random2.py)

Второй скрипт использует тот же исходный список TOP 1000, что и основной скрипт. Однако его функционал упрощён до минимума: при запуске он случайным образом выбирает одну актрису из списка и выводит её данные. Никаких вопросов, оценок и дополнительных действий не требуется.
